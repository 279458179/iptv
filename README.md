# CCTV IPTV 直播源 (IPv4 专用)

自动聚合高质量的CCTV直播源，专为IPv4网络环境优化。

## 特点
- **IPv4 Only**: 严格过滤IPv6地址，兼容旧设备和纯IPv4网络。
- **自动验证**: 每次更新前自动测试连接性，剔除无效链接。
- **低延迟优先**: 优先选择响应速度快的节点。

## 使用方法
1. 复制上面的 `.m3u` 链接。
2. 在 APTV、TiviMate、PotPlayer 等播放器中添加订阅。
3. 享受流畅播放。
